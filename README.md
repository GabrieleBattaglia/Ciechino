# Ciechino, il tiro a segno a orecchio

Un gioco accessibile per chi non vede, e per chi vuole provare a giocare con le orecchie: si spara a bersagli sonori sospesi in uno spazio di 50 metri davanti a te, mirando con tre barre di suono, direzione, alzo e potenza, che si fermano con lo spazio.

Il nome è un gioco di parole fra cieco e cecchino.

Il gioco è in costruzione: la prima versione giocabile arriverà a breve. Il progetto sta in docs/progetto.txt, l'idea di partenza in docs/idea_73.txt.
